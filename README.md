# 校园体育打卡应用 v3 原型项目说明

## 项目背景
本项目是一个基于 React 的移动端体育打卡应用原型，旨在为高校提供一套完整的体育打卡与运动数据管理解决方案。

### 核心设计规范
- **设计系统**：Shadcn UI
- **主题色调**：
  - 校园绿 (`#22c55e`)：代表健康、青春与校园活力。
  - 活力橙 (`#f97316`)：代表能量、竞技与运动热情。
- **适配方案**：完全适配移动端交互，采用响应式布局。

## 模块与页面结构 (共12个页面)
项目已完全实现以下功能模块：

1. **登录与初始化模块**
   - `Splash.tsx`: 品牌启动页，展示应用理念。
   - `Login.tsx`: 支持学工号登录。
2. **核心打卡模块**
   - `Home.tsx`: 运动概览页，集成 GPS 信号监测与快速打卡入口。
   - `ActiveExercise.tsx`: 实时运动监测页，具备防误触滑动锁定功能。
   - `Settlement.tsx`: 运动结算页，趣味化展示卡路里换算。
3. **教务服务模块**
   - `ServiceHub.tsx`: 校园体育服务中心，集成体育课、体测、预约等入口。
   - `Appointment.tsx`: 体育场地在线预约。
4. **数据可视化模块**
   - `ScoreReport.tsx`: 个人体育成绩单，集成雷达图综合素质分析。
   - `History.tsx`: 详尽的运动历史列表。
   - `DataDetail.tsx`: 单次运动的轨迹与深度数据分析。
5. **个人中心模块**
   - `Profile.tsx`: 个人信息、关联设备管理及原型说明入口。
   - `Feedback.tsx`: 打卡异常申诉与意见反馈。

## 核心功能亮点
- **📡 GPS 信号指示灯**：实时模拟 GPS 强度，引导用户在最佳环境下开始运动。
- **🔓 防误触滑动解锁**：针对运动场景优化的“滑动结束”按钮，避免汗水或肢体误触。
- **🍳 荷包蛋卡路里换算**：将消耗的卡路里转化为“荷包蛋”数量，提升运动成就感。
- **📊 雷达图成绩单**：从速度、耐力、频率、参与度、力量五个维度生成身体素质报告。
- **⌚ 多设备集成模拟**：在个人中心展示了与 Apple Watch 和华为手环的同步状态。

## 技术规格
- **前端框架**：React 18+
- **路由管理**：React Router 6 (HashRouter)
- **样式方案**：Tailwind CSS
- **图标库**：Lucide React
- **组件基础**：Radix UI + Shadcn UI
- **类型检查**：已通过 TypeScript 严格检查

## 预览方式
1. 打开应用后，可从 **个人中心 (Profile)** -> **原型功能说明** 进入详细说明页。
2. 应用默认从启动页开始，按照流程体验即可。
